# শরতের চিঠি

First-stage Durga Puja greeting demo built with Next.js, TypeScript, and GSAP ScrollTrigger.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3000. Production verification: `npm run build`.

The demo includes the autumn introduction, scroll-driven envelope reveal, direct greeting button, Bengali greeting, responsive layout, and reduced-motion fallback. Fonts load from Google Fonts with local serif/sans fallbacks. No automatic audio.

Personalization, photo cropping, Supabase persistence, public sharing, private management links, and reporting are later stages; this preview does not publish user data. Sender text is sample content.

Design references in `design/` were produced with the built-in image generation tool. The rendered UI is live HTML/CSS/SVG rather than a screenshot.
