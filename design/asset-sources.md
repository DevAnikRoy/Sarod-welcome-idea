# Real photography used in the website

All three photos were downloaded from Wikimedia Commons. No AI-generated image is presented as a real photograph. Local optimized WebP copies are resized and displayed with CSS crops; these adapted images remain CC BY-SA 4.0. Source photographs are retained alongside them.
